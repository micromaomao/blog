I'm trying to build an interactive demo of a concept mentioned in a 3Blue1Brown math video. Create code in script.ts that:
- Initialize a THREE.js webgl renderer and attach it to the canvas
- In onResize, set the render's size, camera size etc
- The scene should have a background color of #f9f9fa
- The scene should have a simple x-y-z axis with small ticks every 0.2 unit, and no labels, but should have arrows. No need to color then - they can all be a grey color. The axis should be from -1.5 to 1.5 in each direction, and the camera should be in a position to see the entire x-y-z axis. The axis should be 1-to-1 scale.
- Please prefer simple rather than complex code. It's fine for it to look a bit coarse. The arrows can just be small cones.
- If the user use mouse or touch to drag the scene, it should rotate.
- The scene should contain a sphere.
- In order to facilitate animating a smooth transformation of the sphere's surface, it should be created in a special way involving a ShaderMaterial, with a vertex shader that will take in raw longitude and latitude (rather than 3D positions generated by e.g. SphereGeometry), and turn them into 3D position of points on a unit sphere, then projected. Maybe we have to use a PlaneGeometry with controllable segment count?
- Write a simple fragment shader that colors the sphere using simply the longitude and latitude as the UV coordinate, and maps them onto a (computed) chessboard texture with 10x10 blocks. The color should be #3D85C6 and #C4DAED. This color should then be shaded by light - if there is a way to "integrate" this with the THREE.js's light system, then create a directional light pointing toward (-1, -1, -1), otherwise just compute a sensible shading in the fragment shader.
- Define a variable "latCutoff" that initially is set to 90. If it is <90, points above this latitude degree is not rendered.
- You can save the shader code as separate files then import then with webpack raw-loader.
Below the canvas, add a slider (using elem.appendChild()) to control the latCutoff value.
